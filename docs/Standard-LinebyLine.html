Standard - Line by Line

Functions of type eStandardFunction operate on one source line at a time. The engine calls each selected function for every line of every selected file. The line is passed by reference; the function returns True if the line was modified.


Command to function

Each of these replaces a legacy COMMAND with the identically-named modern function, inside a Move statement. The conversion is mechanical and the semantics are unchanged; they are separate functions only so that a workspace can convert one keyword at a time. The command forms are what the compiler flags - the function forms are already modern and are never touched.

AddUseFileExtension

Adds the default '.pkg' file extension to a Use statement that lacks one.

Example: Use cMyClass -> Use cMyClass.pkg

Leaves Use statements that already carry an extension (.pkg, .vw, ...) or a quoted path untouched.

The legacy commands still compile, but they do not work with the Studio's statement completion.

Example: Calc (iA + iB) to iC -> Move (iA + iB) to iC, and MoveInt iVal to iCount -> Move iVal to iCount

Group: Modernization

ChangeCodeJockReportToGrid

Renames the CodeJock symbols that DataFlex renamed from 'Report' to 'Grid' in DF 23.0, when cCJReportControl.pkg became cCJGridControl.pkg.

Covers the Use line, the class names and the xtpReport/XTPReport constants together - the old names are defined ONLY in OldcCJReportControl.pkg, so this is one migration, not two halves.

Examples:

  • Use cCJReportControl.pkg -> Use cCJGridControl.pkg
  • Class cMyGrid is a cCJReportControl -> ... is a cCJGridControl
  • Set piTheme to xtpReportThemeNone -> Set piTheme to xtpGridThemeNone

Matched by CodeJock prefix, so DataFlex's own Report classes and the ComReport* properties are never touched.

OldcCJReportControl.pkg is left alone deliberately. It still defines every old name, so a Use of it keeps compiling (with the 4536 obsolete warning). Converting the Use without the names, or the reverse, is what breaks - so this does both on every line it sees, and never touches the one file that keeps the old names legal.

A class of your own whose name starts with cCJReport or xtpReport is renamed too. Only the BASE class matches, so 'Class cMyGrid is a cCJReportControl' rewrites the base and leaves your own name alone.

Group: Modernization

Fixes compiler message(s): 4313

Example: Define_Auto_Increment Prod0030.Nr To Dokd0010.Nr -> Set Field_Auto_Increment Field Dokd0010.Nr File_Field Prod0030.Nr

Group: Modernization

Fixes compiler message(s): 4533

ChangeGetAddress

Group: Modernization

Fixes compiler message(s): 4533


ChangeGetFileExistsToFileExist

Modernizes the legacy Get_File_Exists utility function (func.pkg) to the File_Exist command.

Example: Get Get_File_Exists sFileName to iExists --> File_Exist sFileName iExists

Note that File_Exist takes no 'to' token. Only the plain Get-call form converts; an expression call like (Get_File_Exists(sF)) is left for a hand fix.

The file argument - a variable, a string literal or a parenthesised expression - is carried across verbatim, so its contents and inner spacing survive even when a literal contains ' to ' or '//'.

Left untouched rather than half-converted: a call with an 'of' clause, a line continued with ';', and any tail that is not 'to <var>'. Re-running is safe - a converted

File_Exist line is no longer a Get statement, so it is never matched a second time.

Group: Modernization


ChangeIfNotCommandToExpression

Changes the legacy IFNOT command AND the two-word 'If Not' command form into an expression.

Examples: IFNOT Found Begin --> If (Not(Found)) Begin;

If Not (Found) Begin --> If (Not(Found)) Begin (a redundant outer paren pair is folded); If Not (iA = iB) Begin --> If (Not(iA = iB)) Begin.

A multi-term unparenthesized condition (If Not a eq b) is left untouched - wrapping only the first operand would break it - as are [bracket] indicator lines (the indicator converters own those).

Group: Modernization


ChangeIndexNumber

Changes index-number references in Find / vFind / Constrained_Find / Constrained_Clear / For_all commands from one index number to another, SCOPED to a single table. Useful after a table-index restructure that renumbers the indexes of one table.

Rewrites both the Index.<N> and the bare-integer form, in these positions: the <N> after a mode keyword on Find / Send Find / Get Find (EQ, GT, LT, GE, LE, NE, FIRST, LAST, NEXT, PREV); the second argument of vFind <tbl> <N> <mode>; the <N> after 'by' on

Constrained_Find and Constrained_Clear; and the <N> after by or down on For_all.

The table is identified case-insensitively, either as a direct token or in DDO form - o<TableName>_DD or o<TableName>_DataDictionary, the two common DataFlex conventions. Any other DDO naming convention is NOT recognised; rewrite those by hand.

sParameter is "<TableName>,<from>,<to>": the table name and two positive, unequal integers, for example "Customer,3,5".

Group: Other

Parameter: "ANY"

Three comma-separated values: the table name, the FROM index number, and the TO index number. Example "Customer,3,5" changes every

Index.3 / by 3 / vFind Customer.X 3 reference for the Customer table to use 5 instead. Both must be positive - DataFlex indexes are 1-based, and

-1 (recnum mode) is never modified.


ChangeIndicatorToBoolean

Modernises a legacy global Indicator declaration to a Boolean global variable. DataFlex Indicator declarations are always GLOBAL. The output is #IFNDEF-guarded so it stays idempotent and cannot duplicate the same name synthesised by DeclareRefactoredIndicators (no 4390), in any compile order.

Example: Indicator User -> #IFNDEF User / Global_Variable Boolean User / #ENDIF (one block per name).

Owns the "Indicator. Use Boolean" variant of 4538 (the DECLARATION). 4538 is a SHARED number: the "Indicate. Use Move command" + "...without parentheses" ([Found] usage) variants route to ChangeLegacyIndicators / ChangeSquareBracketsIndicators - hence the match-text on every 4538 tag.

Group: Modernization

Fixes compiler message(s): 4538


ChangeInToContains

Replaces IN command with expression operator Contains.

It also swap places for the two variables involved and adds paranthesis.

Example: If sSub in sAlphabet -> If (sAlphabet Contains sSub)

Group: Modernization


ChangeLegacyIndicators

Changes legacy 'Indicate' to expression

Paired with ChangeSquareBracketsIndicators: THIS function does the deep transform but deliberately skips lines containing Find/Send/Constrain - the sibling sweeps those up.

Run both together; this one then reports the bulk of the changes.

Examples:

  • Indicate Found as True --> Move True to Found
  • [Found] and [FindErr] indicator statements.
  • [Found| Command -> e.g. If Found Command
  • While [Not Found] -> e.g. While (Not(Found))
  • [~Found] begin -> If (Not(Found)) Begin
  • [Found ~Found] Begin -> If (Found and Not(Found)) Begin
  • [Select] Indicate Select as Windowindex Eq Fieldindex --> Move (WindowIndex = FieldIndex) to Select - [Found]

Indicate Found as Invoice.CustNum eq Customer.Number -> If (Found) Move (Invoice.CustNum eq Customer.Number) to Found - If [Not Found] Reread hTable -> If (Not(Found)) Reread hTable

Limitations: handles at most two booleans within one square bracket, e.g. [Found Select], and leaves the line unchanged if it contains a GROUP or ALL indicator directive.

Group: Modernization

Parameter: "eLeaveSelect, eModernizeSelect"

Default: eLeaveSelect

eLeaveSelect keeps [SELECT] as-is (safe default). eModernizeSelect also needs DefineSelectMacro selected (it defines the SELECT macro).

Fixes compiler message(s): 4538, 4535


ChangeLegacyOperators

Changes legacy comparison operators to: <, <=, =, <>, >, >=

Replaces: gt, ge, lt, le, eq, ne with > >= < <= = <>

It does not change operators in e.g. find operations.

Example: If (iA Eq iB) -> If (iA = iB). LT LE EQ NE GT GE become < <= = <> > >=

Group: Modernization


ChangeLegacyShadow_State

Changes Shadow_State and Object_Shadow_State to Enabled_State

Example: Set Shadow_State [of oObject] to True -> Set Enabled_State [of oObject] to False

Set Object_Shadow_State [of oObject] to True -> Set Enabled_State [of oObject] to False

Group: Modernization


ChangeLegacyTypeCast

Rewrites a legacy type-name cast that DataFlex 26 refuses - Handle(x), Pointer(x), Boolean(x), DateTime(x), UChar(x) - into the modern Cast(x, Type) form. Integer, String, Number and Date are legal casts and are not touched. Clears error 4328, where the compiler names the type's internal name (LONGPTR for Handle, ADDRESS for Pointer) rather than the word in your source.

Examples:

  • Send exportGridToExcel (Handle(Self)) becomes Send exportGridToExcel (Cast(Self, Handle)) - Move (Pointer(0)) to p becomes Move (Cast(0, Pointer)) to p

Why the error row is unreadable without this: 4328 is reported against the type's INTERNAL name, so it names an undefined symbol called LONGPTR or ADDRESS - words that appear nowhere in your source - under a hint about missing database fields and Type members.

A 4328 that names ADDRESS is deliberately NOT offered an auto-fix in the analyzer: Address is also a perfectly ordinary database column name, so such a row is more often a missing field than a Pointer() cast. Those rows keep the generic 4328 hint - run this function and it still rewrites every Pointer() call it finds.

Group: Modernization

Fixes compiler message(s): 4328


ChangeLegacyWorkspaceAccessors

Changes a legacy Workspace path read into the modern cWorkspace property read.

Example: Get CurrentProgramPath of ghoWorkspace to sPath -->

Get psProgramPath of (phoWorkspace(ghoApplication)) to sPath.

Maps the whole retired Workspc.pkg path family (Data / Program / Bitmap / Help / AppSrc / DdSrc / SystemDf / Df / FileList); a name with no modern equivalent (CurrentModuleName, ...) is left untouched. The modern properties read the opened .ws configuration - verify trailing-separator assumptions on review. Companion to RefactorWorkspaceTocApplication (which converts the Workspace OBJECT); this one sweeps the READ sites across all files.

Group: Modernization

Fixes compiler message(s): 4328


ChangeParseFileToExtractFileName

Renames the obsolete global Parse_File() to ExtractFileName(). Same result for any real file specification, and the modern one is pure string handling where

Parse_File probes the DISK (through Parse_Path) to decide whether the last segment is a folder. One difference: given a path whose last segment is an existing directory, Parse_File returned a blank and ExtractFileName returns that name. Its sibling Parse_Path is NOT converted - ExtractFilePath is not equivalent to it (trailing separator and drive letter both differ).

Group: Modernization

Fixes compiler message(s): 4534


ChangeSquareBracketsIndicators

Changes legacy square brackets found indicators; [Found] [FindErr] to expressions; (Found) or (Not(Found)) It does not change the 'Indicate' key word, only change square brackets to expressions.

Paired with ChangeLegacyIndicators, which runs first but skips lines containing

Find/Send/Constrain - THIS function sweeps those up, so reporting few or zero changed lines is NORMAL when both are selected.

Sample Code:

  • [Found] and [FindErr] indicator statements to (Found) and (FindErr).
  • [Found| Command -> e.g. If (Found) Command
  • [FindErr] Send Rebuild_constraints of oDD -> If (FindErr) Send Rebuild_constraints of oDD - While [Not Found]

-> While (Not(Found)), and [Not Found] While likewise

  • If [Not Found] Reread hTable -> If (Not(Found)) Reread hTable
  • [~Found] Begin -> If (Not(Found)) Begin
  • [Found ~Found] Begin -> If (Found and Not(Found)) Begin

Limitation: leaves the line unchanged if it contains a GROUP or ALL indicator directive.

Group: Modernization

Parameter: "eLeaveSelect, eModernizeSelect"

Default: eLeaveSelect

eLeaveSelect keeps [SELECT] as-is (safe default). eModernizeSelect also needs DefineSelectMacro selected (it defines the SELECT macro).

Fixes compiler message(s): 4538, 4535


ChangeSysdate

Migrates the obsolete Sysdate / Sysdate4 commands to the modern CurrentDateTime() function.

Example: Sysdate dToday -> Move (Date(CurrentDateTime())) to dToday

The rarer date+time form (Sysdate dDate tTime) is left with a // TODO (DFRefactor) marker for a hand conversion - its time receiver can't fold into one CurrentDateTime() call.

Matched only at a COMMAND position, so a variable named 'sysdate' or a passing mention never triggers. An inline-If nose form (If (x) Sysdate dDate) is deliberately left for manual work; the TODO marker on the date+time form also keeps the analyzer quiet about that line.

Group: Modernization

Fixes compiler message(s): 4533

SplitInlineIfElseLine

Splits If/Else single lines to If/Else - Begin constructs.

It does not split if the last word is = "Break", as that could change the program logic.

The function accepts a parameter controlling the If/Else or Begin/End block constructs.

Valid sParameters, See: EnumList;

Example: If (iRetval = 0) Procedure_Return -> If (iRetval = 0) Begin / Procedure_Return / End

Group: Tidy Up

Parameter: "eSplitBySpaceAndSemicolon, eSplitBySemicolon, eSplitToBeginEndBlock"

Default: eSplitToBeginEndBlock

Valid values; eSplitBySpaceAndSemicolon - Split line with space and semicolon eSplitBySemicolon - Split line with semicolon eSplitToBeginEndBlock - Use a Begin/End block


UnicodeOemAnsiFunctions

Unicode fix for the legacy OEM/ANSI string-conversion calls: rewrites

ToOEM(x) to Utf8ToOem(x) and ToANSI(x) to Utf8ToAnsi(x). Whole-word and idempotent (an already-converted Utf8ToOem is left alone); skips strings and comments.

Group: x64 + Unicode

Fixes compiler message(s): 4534


Win64AddressToPointer

64-bit modernization: rewrites the declaration type Address to Pointer (the guide's named replacement for the native pointer type) - local variables, struct members,

Property and Global_Variable declarations. Whole-word and idempotent; never touches

AddressOf, fields, or a variable named "Address". Params/Returns types are out of scope.

Group: x64 + Unicode


Win64WindowLongFunctions

64-bit fix for the Win32 "long" calls that truncate pointers: rewrites

GetWindowLong/SetWindowLong/GetClassLong/SetClassLong to their *Ptr variants

(GetWindowLongPtr, etc.), which are pointer-safe on both 32- and 64-bit.

Whole-word and idempotent; skips strings and comments.

Group: x64 + Unicode
