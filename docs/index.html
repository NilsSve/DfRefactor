Welcome to DFRefactor

DFRefactor is a free, open-source tool for automated refactoring of DataFlex source code. It applies behavior-preserving transformations that bring legacy code in line with modern DataFlex syntax — and, when you move a workspace to a newer DataFlex, converts the constructs that release no longer accepts.


"Any fool can write code that a computer can understand. Good programmers write code that humans can understand."

— Martin Fowler, Refactoring: Improving the Design of Existing Code (2nd edition, 2019)


DFRefactor is inspired by the discipline of refactoring as formalized in Martin Fowler's seminal work. See What Is Refactoring? for background.


Where to start

  • Overview — what the program does, and what it will not do. Start here.
  • How to use the Program — a complete session, step by step, in the order the program expects it.
  • Refactoring Functions — what each individual function changes, with before-and-after examples.

In short: open a workspace, choose the DataFlex version you are moving to, then take either the Guided route — one Check that compiles and scans, and hands you a ranked list to approve — or the Manual route, where you pick the folders and functions yourself. Nothing is written until you approve it, and every file changed is backed up first.


Components

You run one program. The rest are support, and most of them start themselves:


Program

Audience

Purpose

DFRefactor

All users

The refactoring application. Everything in this help refers to it.

TestBench

Writing your own functions

A workbench for developing and testing a refactoring function of your own before putting it to work: it runs your function over a scratch file and shows the before and after side by side. It also carries the JSON Export/Import facility, which is how you send a function you have written to RDC Tools for inclusion in the shipped library. Only needed if you add functions to UserDefinedRefactorFunctions.pkg.

DFUnit_TestRunner

Optional

The unit-test runner for DFRefactor's own function library, bundled so you can run the suite yourself. Not needed for refactoring. The DFUnit framework was originally developed by Ola Eldøy, enhanced by Bram NijenKamp, and adapted for this project.

DUFUpdateProgram

Never run directly

The database updater. DFRefactor launches it when its own tables need migrating.
