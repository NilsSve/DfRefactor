If you are new to DFRefactor, read these two topics first, in this order:

  • Overview — what DFRefactor does and does not do, and the two ways of working with it.
  • How to use the Program — a complete refactoring session, step by step.


The cycle

Modernizing a workspace is done in repeated rounds rather than in a single pass. The Refactor Cycle describes each part of a round:

  • Check - Compile + Analyze — compiling the program with the DataFlex version you are moving to, and reviewing the compiler's messages.
  • Compiler Output — the complete output from the compiler, for when you need to see it unchanged.
  • Analyzer — the list of findings, sorted by priority, and how to turn it into a refactoring plan.
  • Manual Changes — the changes that a refactoring function did not make, and why.
  • Analyze Source — finding obsolete code that still compiles without any error or warning.
  • Modernization Progress — a record of each round, showing how the number of findings goes down.
