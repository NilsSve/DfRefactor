  1. Refactoring Functions

Report — All Files

Functions of type eReportFunctionAll scan all selected files together and report findings; they make no changes to the source code. Each writes its results to a log file reachable from the Other Log files dialog in the toolbar.


FunctionReturnMismatchReport

Reports Only! Makes no changes to the source code. Pass an array with all selected source files.

Finds the DECLARATIONS behind DF 25/26 error 4544: one message name declared with more than one return type. Lists every declaration of each contested name - your own AND the ones the target DataFlex ships - so you can fix the handful that cause it instead of the hundreds of call sites it flags.

Group: Modernization


GosubGotoReport

Reports Only! Makes no changes to the source code. Pass an array with all selected source files.

Maps every legacy Gosub subroutine - labels, call sites, Gosub_Returns, ON..GOSUB dispatches - with a per-subroutine verdict: CANDIDATE for Procedure extraction vs MANUAL (and why). Classifies every Goto with a rewrite hint: forward skip -> If/Else block; backward jump -> While/Repeat loop; boundary-crossing -> untangle first.

Group: Modernization

Fixes compiler message(s): 4533


LegacyDbApiReport

Reports Only! Makes no changes to the source code. Pass an array with all selected source files.

Inventories the legacy Database-API attribute commands (File_Size, Size_of_Field, Get_Current_Lockcount, Get_date_format, Get_number_format, Get_filelist, Set_filelist, Get_Date_Attribute, Ifchange) and names the modern Get_Attribute/Set_Attribute replacement for each site. They need a hand migration (multi-format / structural / ambiguous), so nothing is rewritten.

Group: Modernization


LegacyDfPathReport

Reports Only! Makes no changes to the source code. Pass an array with all selected source files.

Inventories the obsolete Set_dfpath command (it replaced the whole DFPATH; char-mode only) and, per site, explains the modern cWorkspace pathing choice: delete (paths come from the .ws config), append to psSystemDfPath to add a directory, or - rarely - Set psDfPath for a true replace (which wipes the system dirs). A per-site judgement, not a 1:1 swap, so nothing is rewritten.

Group: Modernization


LegacyFieldOptionsReport

Reports Only! Makes no changes to the source code. Pass an array with all selected source files.

Inventories the character-mode field entry options (autofind, capslock, displayonly, findreq, forceput, noenter, noput, skipfound, retainall, zero_suppress, autofind_ge) and names the modern DataDictionary Field_Options target per site. The modern setting lives in the DataDictionary class (a cross-file change), so nothing is rewritten.

Group: Modernization


LegacyRegistryReport

Reports Only! Makes no changes to the source code. Pass an array with all selected source files.

Inventories the legacy Windows-Registry / profile-string / INI commands (Reg_Open_Key, Reg_Enum_Value, Get/Set_Profile_String, Get/Set_Registry_Root, Read_dfini, ...) and names the modern class for each site (cRegistry, or cIniFile for Read_dfini). cRegistry is an object model, not the legacy handle/callback one, so these need a hand port.

Group: Modernization


LegacySqlReport

Reports Only! Makes no changes to the source code. Pass an array with all selected source files.

Inventories the legacy Embedded-SQL commands (SQLConnect, SQLOpen, SQLPrepare, SQLExecute, SQLFetch, SQLGetData, CLI_*_Attribute, DB2_/MSSQL_SetConstraint, ...) and names the modern cSQL* class.method per site (cSQLHandleManager / cSQLConnection / cSQLStatement). A stateful object port, not a 1:1 token swap, so nothing is rewritten.

Group: Modernization


TypeToStructReport

Reports Only! Makes no changes to the source code. Pass an array with all selected source files.

Lists every legacy Type definition with a proposed modern Struct, tagged [MARSHALED to native code - hand-migrate] vs [pure in-memory - safe to convert], plus the buffer accessors (Put / GETBUFF / StoreField / ...) to hand-migrate. Each pure in-memory Type's usage clusters are graded AUTO-CONVERTIBLE vs BLOCKED (with the exact reason).

Group: x64 + Unicode

Fixes compiler message(s): 4532, 4536, 4533, 4534


UnicodeWin64ReportExternalFunction

Reports Only! Makes no changes to the source code. Pass an array with all selected source files.

Audits every External_Function / External_Procedure declaration: flags Integer/DWord parameters or returns whose name signals a pointer-sized Windows type (hWnd, lp*, lParam, *size*, ...) that should be Handle/Pointer/Longptr/ULongptr, and String parameters in an ANSI ("...A") entry-point wrapper that should be WString. Then lists every CALL SITE of each ANSI wrapper - the A-to-W migration blast radius - tagging address-taking buffer calls [structural].

Group: x64 + Unicode


UnusedSourceFiles

Reports Only! Makes no changes to the source code. Pass an array with all source files.

Checks all files in the current workspace to see whether they are used, and lists those that are not. Returns a list of unused files.

Alongside the report, a companion 'MoveUnusedSourceFiles.bat' is also written to the DFRefactor_Backup folder. Running it MOVES (never deletes) the listed files into a quarantine sub-folder, so the cleanup is reversible. Running it is entirely optional; the report's footnote points to the .bat and explains how to undo it.

Group: Tidy Up


UnusedUseStatements

Reports Only! Makes no changes to the source code. Pass an array with all selected source files.

For each file, scans all Use statements and finds all classes defined in each Use file. Reports any Use file whose classes are never instantiated by an Object in that file. Use files that contain only procedures or functions (no Class definitions) are excluded. Results are accumulated across all files into a single log file.

Group: Tidy Up


Win64PointerTruncation

Reports Only! Makes no changes to the source code. Pass an array with all selected source files.

64-bit truncation audit: flags a pointer-sized value moved into a 32-bit Integer/DWord (which silently truncates on x64) - either a declared Pointer/Address variable or parameter, or an AddressOf() result, assigned into an Integer/DWord. Per-method scope.

Group: x64 + Unicode


Win64StructPadding

Reports Only! Makes no changes to the source code. Pass an array with all selected source files.

64-bit struct-padding audit: in each Struct...End_Struct, flags a pointer-sized member (Pointer/Address/Handle/Longptr/ULongptr) that does not land on an 8-byte-aligned offset and so needs an Is$Win64 filler. A struct with an indeterminate-size member, or that already uses an Is$Win64 conditional, is noted or skipped.

Report-only - apply the actual fix with DAW's "Structure Padding Helper" tool. DataFlex structs do not auto-pad the way C does, so the fix is an explicit filler member guarded by the compiler flag (#IFDEF Is$Win64 / Integer iAlign / #ENDIF) inserted ahead of the misaligned member in a struct that mirrors a Win32 API structure.

Group: x64 + Unicode
